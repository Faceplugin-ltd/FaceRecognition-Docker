# Runtime libraries

Download the **FaceRecognition-Linux-fast** Drive folder into `cpu/`:

https://drive.google.com/drive/folders/11XBHzGVosF7742_LdToXG4dZ160uYQCu?usp=sharing

Expected files (CPU):

- `libFaceRecognitionSDK.so`
- `libfacerec.so`
- `libonnxruntime.so`, `libonnxruntime_providers_shared.so`
- `far.fpk`
- `libfal-eng.so`, `fal.fpk`

Then `./run.sh` or `docker compose up --build`.
